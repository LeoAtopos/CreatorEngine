# 创作引擎

现在的游戏引擎都是“制作引擎”，而这是辅助游戏创作者进行创作构思的“创作引擎”。从最初的想法开始，通过格式化的文本填空，帮助创作者梳理游戏的构思。

说不清楚的，往往也做不明白。创作引擎的基础理论是言语化设计。强迫创作者提前思考，以免构思不充分造成设计遗漏、浪费时间。

说不清楚的，往往也做不统一。若游戏需要大量深度的思想同步，多人完成。前期花大量时间做深度的言语化沟通，是绝对必要的。

## 二、实践用途

1. 制作游戏前，理清创作思路，查漏补缺。
2. 制作游戏前，用于比较筛选可做的项目。
3. 制作游戏中，保持更新，保持团队认知同步，理解清晰。
4. 制作游戏后，再次检查，根据反馈调整，找到差异和问题所在。
5. 用于研究其他游戏，锻炼整体设计构思能力。
6. 概括玩过的游戏，理清游玩体验，达成与创作者的共鸣。

## 三、深度使用说明

逐条解释每一步的意义，及引申思考。

### 1. 最初想法

这里记录构思游戏的最初想法。诚实填写初心，可用于以下设计思考：

1. 明确创作动力，感知当时情绪的强烈程度。
2. 记录初心，用于检查之后是否偏离，是否遗忘。并不是说初心不能改，但如果发生变化，这个时刻很关键，需要留这个记录来做提醒。
3. 用于理解之后各项设计的思路起点，是补充，是落地，是加强，还是有冲突。

### 2. 三句话

根据电梯30秒原则，创作者应具有将游戏在30秒内介绍出来的能力。30秒应该只够说三句话。

这里的三句话分别阐述什么游戏，什么体验，这体验如何验证三个点。

反过来，通过这三句话，也是可以帮助创作者完成游戏构思的工具。

```
玩家作为___身份___，反复___核心动作___，以___目标___；但___约束或反转___。
```

这是一句最简练的阐述游戏是什么的话。

**身份**，或者说角色，是玩家可代入的主体视角。

- 一个玩家熟知又新鲜的身份，可以让玩家产生足够的期待，快速进入fantasy。
- 如杀手，猎人，工匠这样的身份更可以快速建立游戏目标和能力认知，让玩家快速上手游戏机制。
- 无聊无感的身份让玩家失去兴趣，感觉怪异，不可理解。

**核心动作**，是游戏的机制核心，动词动作是游戏互动设计的根本。

- 游戏有高度可重复的核心动作，才能给到玩家足够的游戏时长。
- 核心动作根本的定义了游戏的类型和特色，游戏机制围绕核心动作展开，且通常不应与核心动作冲突。
- 动作无核心，或，核心非动作，都将成为无法建立游戏性的大问题。

**目标**，阐述游戏在叙事和意义层面的玩家动机。

- 好的目标让人向往，满心期待，可以延伸出更多中间目标。
- 明确目标让玩家能够更投入，不会迷茫流失。
- 缺少目标，目标不吸引人，将会断裂创作者和玩家间的共同关注，进而失去理解和共鸣。

**约束或反转**，点出游戏的障碍难题，也就是问题的有趣点所在。

- 约束或反转展现出游戏的与众不同，风味特点。
- 好的约束或反转通常需要和身份或核心动作有冲突，与目标有矛盾。
- 缺少明确的约束或反转，将会使游戏平淡无味。


```
为___目标玩家___提供___核心感受___，主要通过___关键动态___来实现，而不是依赖___常规方案___。
```

这一句重点在表达游戏体验。

**目标玩家**，游戏创作的对象，明确这个对象感对于创作的取舍非常重要。

- 没有适合所有人的游戏，好游戏永远是相对于某一批人的。
- 虽然总有目标玩家之外的玩家会喜欢你的游戏，但创作者必须首先明确并服务好目标玩家，再谈别的。
- 目标玩家指导游戏的一切设计，游玩门槛和机制取舍等等的一切。

**核心感受**，从目标玩家角度总结游戏带来的感受性价值。

- 感受确实是难以描述的，所以需要诸多参考和训练才能把握。
- 放松，紧张，深刻，浅刺激，探索，挑战体验还是什么，总能挤出一些词，而这个感受会在游戏构思和开发过程中逐渐更新并明晰。
- 非核心的感受也是有益的调剂，但必须不能破坏核心感受。

**关键动态**，是生成核心感受的，游戏中可以发生的事件的叙事。

- 需要通过关键动态的描述来说明核心感受的来源，感性的判断其中的关联。
- 游戏中发生的玩家行为和反馈，是否支持核心感受，是这里最重要的问题。

**常规方案**，是指区别于实现某核心感受其他游戏使用的常规办法。

- 这是提醒创作者去研究参考其他同方向的游戏。写不出来，说明对该类型的研究深度不够，可能会在重复造轮子，重复他人。
- 了解常规方案也是作出创新的基点。
- 常规方案也是用来指导后续设计需要避免的点。


```
如果让玩家___执行的机制___，那么他们会___产生的行为或策略___，进而感到___目标体验___；证据是___可观察信号___。
```

这句话是对游戏目标体验如何达成的验证性思考。理论基础是机制-动态-美学的MDA模型。

目标体验，是这句话的核心，需要先说明。

- 目标体验就是上一句“什么体验”的概括，重复。
- 目标体验是MDA中的A，广义美感。
- 目标体验不是指游戏的全部体验，是指游戏最核心的体验。

执行的机制，是为了达成目标体验，需要玩家进行的条件观察和行为。

- 这里的机制不是指概括的机制，或所有的机制，而是与实现目标体验最紧密关联的机制。
- 文本需要描述玩家执行这个机制的过程，即与这个机制的互动过程。
- 执行机制是MDA中的M的部分，机制的部分，通常是游戏的核心机制或特色机制。

产生的行为或策略，是玩家做了某些机制行为后产生的动态反应。

- 这里描述了MDA中的D的部分，动态的部分。
- 玩家通过在机制中的行为，产生了什么样的行动模式或策略想法。
- 这是从玩家侧角度考虑的玩家行为。

可观察信号，是一个验证性描述，假设性的描述，玩家行为的预期与解读。

- 通过预测细节的行为与表征，提出证明目标体验通过MDA达成的证明。
- 这强迫创作者提前做观察准备，在观察玩家试玩和反馈中不迷失。
- 缺少可观察信号的构思，创作者极有可能陷入自我感动中。

### 3. 四大设计支柱

叙事、机制、美学、技术的四大设计支柱来自《全景探秘游戏设计艺术》一书。

游戏可以有无数角度或切片去分析，但这四大设计支柱是能够较为全面且不重叠的展现游戏设计概念的好结构。

四个支柱都采用了**类型化加风格特色**的描述结构。这符合人们对事物的认知过程，即大致是什么，独特细节是什么。由于我们至今也不可能完全从0到1创造什么新东西，我们总是在某个已有设计上做发展创新，这样的描述结构也有利于创作者理解自己的地基和个性。

- 四大设计支柱的填写可以帮助创作者了解自己的强项和弱项，缺少考虑的点。
- 缺少明晰的基础框架（类型化），说明这方面的研究参考不够深入，可能要去踩前人踩过的大量的坑。
- 缺少明晰的风格特点，说明在这方面的体验较弱，不能成为购买和游玩的理由。
- 游戏体验是一个整体没错，但做具体设计和具体问题分析的时候，必然要做拆解。
- 游戏可以某一方面不强，但不能没有，且需要某一方面很强。

四个支柱描述完后，追加了每一项**对其他三项的指导，支持和要求**的内容。这是为了避免游戏框架的松散。

- 游戏常见的设计问题就是内在矛盾，尤其是四大设计支柱间的矛盾。
- 四大支柱单个看是ok的，但与其他三者关联不大，或有矛盾，将是灾难性的。
- 单个设计支柱对其他支柱的指导、支持或要求是强迫思考四者间的有机关系，这不但是为了让游戏更加整体和谐，更是挑选设计的重要参考标准。
- 四大设计支柱的互相关联内容越丰富，游戏体验越整体，越少割裂感。

游戏协同分工的时候，四大设计支柱的言语化描述将会是指导协同各个不同工种工作的思想原则。

### 4. 玩家侧构思

游戏创作者最常忽略的一点就是从玩家角度的思考，陷入自嗨情节中。

为达成游戏在玩家侧的体验实现，我们必须想象玩家是如何体验游戏的。

玩家侧的三句话概括了玩家从接触游戏到开始游戏到获得游戏体验的全过程，也是一个理想化的过程。

虽然每个玩家的游戏体验都很不同，但至少设计者需要想象出一个标准过程。以验证设计预期，应对玩家实际体验的反馈。

```
玩家看到游戏名称、介绍图，会认为这是一个关于___主题___的___类型___游戏，会和___关联游戏___关联比较，并产生___体验预期___的预期。
```

玩家进入游戏前的体验往往被创作者忽略。但这严重决定着游戏作品能够给到多少玩家。

**主题**，或者说题材，是侧重内容关于什么的分类。

- 题材的大众小众直接影响玩家受众的大小。根据题材，创作者要调整自己的游戏受众的预期。
- 创作者最好选择自己熟悉的题材，是这个题材前5%的深度理解的人。如果当前没做到，就需要在这方面补课。
- 必须要问的是玩家看到游戏名称、介绍图是否会明确对题材的认知，如果不能，那将会必然流失一部分目标玩家，也有可能进来一些不合适的玩家。

**类型**，是侧重游戏机制的分类。

- 类型的作用与主题类似，帮助玩家建立后续的体验预期。

**关联游戏**，是一个产生预期的重要基础。

- 由于大量游戏玩家，尤其是接触你的作品的初期尝鲜玩家，极有可能是深度玩家，所以他们看到游戏名称和介绍图的时候一定会产生关联联想，会和其他可关联的游戏比较。
- 这些关联游戏将会是他们形成游戏期待的起点。
- 如果玩家不清楚会有哪些关联游戏，玩家就很难产生明确预期，也就会缺少体验动力。
- 如果创作者自己不清楚会有哪些关联游戏，需要去做玩家调查，否则将不能正确感知玩家的预期，导致后续设计不符合预期而不自知。

**体验预期**，玩家进入游戏前产生的预期。

- 不能将创作者的目标体验直接当作玩家侧的体验预期。
- 体验预期是由进入游戏前的信息决定的，有时候可以故意造成体验预期和实际体验的差异，但必须清楚可控。
- 最好还是能做好预期建设，让玩家产生创作者想要的体验预期。

```
玩家在体验游戏10分钟内___会/不会___获得体验预期，___还能/而是___获得___独特体验___，玩家因此而不会离开游戏，并产生___目标/期待___。
```

这一句是从玩家侧构思进入游戏后前10分钟的体验。

游戏的第一印象，十分重要。玩家会在这个时候做出是否继续游戏的重要判断。

**会...还能 / 不会...而是...独特体验**，满足游戏前的预期则增强更多的独特体验，挑战了游戏前的预期则需要给出足够扭转预期的新的独特体验。

- 虽然不是所有游戏都是前10分钟定生死的，但大部分游戏不会有强力的市场宣传和大V背书，玩家的耐心是有限的，是需要考虑前10分钟惊艳玩家的。
- 游戏的独特体验，需要尽早放出，也就是在当前阶段。不是说所有的独特体验都要挤在前10分钟，但前10分钟至少需要让玩家感受到独特体验而不无聊。

**目标/期待**，指前十分钟后玩家获得的继续游戏的动力。

- 建立目标预期，形成游玩动力，是游戏早期的首要任务。
- 缺少期待，目标不明，是很多玩家流失的重要原因。
- 这部分将反应游戏前期的引导，叙事和机制设计的问题。

```
玩家中后期体验的变化是来自___机制/内容___的出现，并最终在游戏结束时，获得___游戏体验___的终极体验。
```

这一句是玩家基本完成游戏体验后的感受，这将最终决定玩家对游戏的评价，进而决定游戏的口碑和传播效果。

**机制/内容**，是指中后期游戏内的变化与新增点。

- 缺少中后期机制内容上的变化，将会使游戏单调无聊。
- 某种机制或内容上的主线变化，是形成游戏价值提升的重要手段。
- 涌现，反转，长任务都是可以考虑的方向。

**游戏体验**，这里指某种终极的，到后期才完整的，包含在创作者的目标体验中的体验。

- 游戏不仅要满足预期，其提升价值在超出预期的部分。
- 终极体验决定游戏的上线。
- 终极体验通常与某种宏大叙事或上升价值关联在一起。
- 缺少终极体验不是不行，只是价值感会较低。
