# 创作引擎：游戏设计 MVP

一个完全本地、规则驱动、不使用 AI 的游戏创作引擎网页应用。它用六步对话式流程，帮助创作者把模糊的最初想法整理成可导出的游戏设计方案。

## 当前流程

1. 记录最初想法。
2. 通过“核心火花、玩家行为、体验承诺”三轮输入澄清想法，并由作者重新表述。
3. 选择玩家 Fantasy，并把通用 Fantasy 写成项目自己的体验目标。
4. 定义游戏类型、目标用户和体验差异化 X。
5. 定义叙事、机制、美学、技术四类关键设计点。
6. 汇总成完整方案，可返回任一步修改、复制 Markdown 或下载 `.md` 文件。

每个抽象概念旁都提供默认收起的参考提示或案例。左侧“设计路径”和右侧“当前设计状态”均可展开或收起。

## 本地与隐私

- 运行时不调用 AI、模型或任何网络 API。
- 项目数据自动保存在当前浏览器的 `localStorage` 中。
- 旧版原型中记录的最初想法会在首次打开时迁移到新版流程。
- “重新开始”会在确认后清除当前浏览器中的项目数据。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:3000/`。

## 验证

```bash
npm run lint
npm test
```

`npm test` 会先完成生产构建，再检查服务端首屏和本地工作流契约。
